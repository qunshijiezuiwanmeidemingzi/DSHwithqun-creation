# 音乐转码工具

把「假 MP3」转成真 MP3，让老式 MP3 播放器不再跳歌。

![检查输出示例](<屏幕截图 2026-11-18 222133.png>)

## 问题出在哪

网上很多 `.mp3` 其实内核是 MP4/AAC 或 FLAC，只是被人把后缀改成了 `.mp3`。

普通播放器能解，但廉价 MP3 播放器只认 MPEG-1 Layer III，拿不到时长就直接跳过——表现就是「点一首歌它自己跳走」「列表里有但点了不播」。

跟 TF 卡大小、跟文件几 MB 都没关系：29MB 的能放、2MB 的反而跳，都是这个原因。

## 三个入口

把歌曲文件、或整个文件夹，直接拖到 `.bat` 图标上：

| 入口 | 作用 |
| --- | --- |
| `好歌一键转MP3.bat` | 在原文件夹生成 `已转MP3\` 子文件夹 |
| `检查能不能播.bat` | 只看不动手，列出每个文件的真实编码 |
| `转换并拷进TF卡.bat` | 转好直接写进 `F:\` 卡根目录 |

## 安装

1. 下载本仓库：右上角 `Code` → `Download ZIP`
2. 解压，双击任意 `.bat`，或者把歌拖上去

ffmpeg 已经内置在 `tools\` 里，不需要另外下载。

## 它做了什么

- **不是 MP3 的**：转成 MP3，恒定码率 192kbps / 44100Hz / 立体声，几乎所有播放器都认
- **本来就是 MP3 的**：一个字节都不重新编码，只去掉内嵌封面和多余标签，完全无损
- 标签只写标题，用 ID3v2.3，不写 ID3v1（避免部分播放器显示乱码）
- 递归扫描时会跳过 `已转MP3\`，成品再拖一次也不会被重复处理

## 自己确认一首歌能不能放

1. 拖到 `检查能不能播.bat`，它会直接说「编码是 aac，不是 MP3」
2. 或者看文件头：`ID3` 开头是真 MP3，`ftyp` 开头其实是 MP4/M4A——**改后缀没有用**

## 注意

- 卡必须是 FAT32、簇 ≤ 32KB。64GB 以上的卡默认 exFAT，要先格式化
- 歌尽量放卡根目录，不少播放器不递归扫描子文件夹
- 卡根目录的 `FILE.IDX` / `MIDX` 是播放器自己的索引，换歌后列表不正常就删掉，插卡会自动重建
- 别把「格式化重传」当万能药，编码不对怎么传都会跳

## 目录结构

```
mp3fix.ps1              干活的主脚本
好歌一键转MP3.bat        入口：转码到「已转MP3」
检查能不能播.bat         入口：只检查不转换
转换并拷进TF卡.bat       入口：转码并写入 F: 卡
说明.txt                随包说明书
tools\                  内置 ffmpeg 及依赖 DLL
```

### 关于 `tools\` 里的 ffmpeg

精简编译版，只保留了转码需要的组件（libmp3lame 编码、AAC/FLAC 解码、MP3 封装等）。`ffmpeg.exe` 约 13 MB，加上依赖的 9 个 DLL 合计约 22 MB。注意这些 DLL 是必需的，单独拿走 `ffmpeg.exe` 会起不来。

由 [RenamePro](https://github.com/Ha2eS1onn/RenamePro) 项目自行编译。该构建启用了 GPL 组件（如 libx264），按 GPLv3 分发，许可证见 [GPLv3 全文](https://www.gnu.org/licenses/gpl-3.0.txt)，源码与构建方式见 RenamePro 仓库。
