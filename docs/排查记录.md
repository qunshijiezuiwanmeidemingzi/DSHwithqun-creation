## 一、问题现象

在*******「*********」买的带屏 MP3 播放器，插 TF 卡放歌时会自动快放跳过：

- 点某首歌，它自己跳到另一首
- 有几首歌列表里有，但点了不播
- 同一张卡、同一个目录下，有的能放有的不能

卖家给的说法是：卡要 FAT32、歌必须是 MP3、文件不能超过 4MB。

## 二、排查过程与结论

先查卡：`F:` 是 FAT32、32GB、簇大小 32KB —— 完全符合卖家要求，卡没问题。

再查文件完整性：卡上 7 个文件全部能正常解码，没有损坏。

**关键反证 1**：29MB 的那首能正常播放 → "不超过 4MB" 不成立。

**关键反证 2**：320kbps 的 MP3 能播 → 码率也不是原因。

**真正原因**（ffprobe 查真实编码后确认）：后缀是 `.mp3`，但内核不是 MP3。

卡上原来 7 个文件的真实格式：

| 文件名（原后缀 `.mp3`） | 真实格式 |
| --- | --- |
| world.execute(me).mp3 | MP4 / AAC-LC 44.1kHz 4.87MB |
| 七朵组合 - 咏春.mp3 | 真 MP3 128k 44.1kHz + mjpeg 封面 |
| 王菲《我爱你》歌词纯享版 .mp3 | MP4 / AAC 48kHz 8.13MB |
| 白fi …「Chain of the Abyss」.mp3 | 真 MP3 320k + 880KB PNG 封面 |
| 相思 - 琵琶行纯享.mp3 | 真 MP3 320k 48kHz + mjpeg 封面 |
| 蔡琴 你不要那样看着我的眼睛.mp3 | MP4 / AAC 48kHz |
| 蔡琴 雨中城市 .mp3 | MP4 / AAC 44.1kHz 2.21MB |

`D:\download` 里的大文件同样中招（"无损"其实也不是 FLAC 文件）：

| 文件名 | 真实格式 |
| --- | --- |
| 大《不死鸟》- 霍尊 .flac | FLAC 96kHz 装在 MP4 容器里 70.63MB → 放不了 |
| 大王菲《我爱你》.MP3 | FLAC-in-MP4 57.47MB → 放不了 |
| 大蔡琴《你不要那样看着我的眼睛》.MP3 | FLAC-in-MP4 56.40MB → 放不了 |
| 大雨中城市-蔡琴.flac | 真 FLAC 29.09MB → 能放 |

所以"29MB 那个反而能播"的真正原因：它是唯一一个真 FLAC。

## 三、结论

播放器只认 MP3（MPEG-1 Layer III）。AAC / FLAC 解不出时长 → 直接跳过。

跟 TF 卡、跟文件大小、跟"格式化重传"都没有关系。

卖家让你"格式化重新传"是无效建议：传输方式改变不了文件编码。

### B. 其他善后

- 原始 7 个文件已移到 `D:\download\TF卡原始文件备份\`（没有删除）
- 成品另存一份在 `D:\download\TF卡修复后MP3`
- 删掉了卡根目录的 `FILE.IDX` / `MIDX` —— 这是播放器自己的歌曲索引，里面残留旧文件名会导致"列表里有但点了跳过"，插卡会自动重建
- 修掉了 ID3v1 中文乱码：之前版本写进去的是 UTF-8 字节，在某些播放器上标题会显示成乱码，已无损重写为干净的 ID3v2.3 标题
